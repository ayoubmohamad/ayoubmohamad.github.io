How it works

  • The router is the gateway for every network. It runs DHCP, DNS, the firewall and internet sharing.
  • The switch connects wired devices. Each port belongs to one network, and one 10G link carries all of them to the router.
  • Networks reach each other only through the rules in Access.
  • Management is limited to two networks.

Firewall policy

  • Everything between networks is blocked unless a rule allows it (default deny).
  • Networks 10, 20, 30, 40 and 50 can reach the internet. Management (99) is limited to secure web traffic.
  • Nothing new is accepted from the internet side.
  • Personal devices and the TVs can reach only the media server.
  • The admin network can manage the servers and the network equipment, and nothing else can.
  • Rules are narrow: one source, one destination, one service.

Making a change safely

  1. Open a command-line session on the device.
  2. Press Ctrl+X. The prompt shows <SAFE>.
  3. Run the change and check it.
  4. Press Ctrl+X again to keep it, or Ctrl+D to undo everything.

If the session drops, the device undoes the change by itself.

What comes next.

Everything that can be built without the internet is built. These steps follow, in order.

Connect the AT&T cable

Plug a BGW320 LAN port into router ether1 and leave the BGW in its normal mode. Then check the address, DNS and the clock.

Update firmware

Once the internet cable is in, update the router, switches and access point.

Install the U7 Pro

Adopt it in the Cloud Key, then create the Personal, IoT and Guest Wi-Fi networks.
